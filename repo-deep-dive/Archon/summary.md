# Archon: Summary

Archon is an open-source workflow engine for AI coding agents — a platform that makes AI-assisted software development deterministic and repeatable by encoding development processes as YAML-defined DAG workflows. It solves the problem of unpredictable AI coding behavior for individual practitioners and small teams who want reliable, structured automation: planning, implementation, validation, code review, and PR creation always execute in the same sequence, with AI providing intelligence at each step but the structure owned by the developer. The architecture is a Bun + TypeScript monorepo with eight packages (`@archon/core`, `@archon/workflows`, `@archon/isolation`, `@archon/git`, `@archon/adapters`, `@archon/server`, `@archon/cli`, `@archon/web`) where a central orchestrator routes messages from platform adapters (Slack, Telegram, GitHub, Discord, Web UI, CLI) through a DAG executor that runs nodes concurrently, with every workflow run isolated in its own git worktree via `@archon/isolation`. What makes it particularly notable is its composability of deterministic nodes (bash scripts, test runners) with AI nodes (Claude via `@anthropic-ai/claude-agent-sdk` or Codex), combined with a router AI that selects the right workflow from natural-language requests — plus 17 bundled default workflows (like `archon-fix-github-issue` and `archon-idea-to-pr`) that serve as customizable starting points committed directly to each repo.
